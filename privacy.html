Nexus-Backup Privacy Policy

Last updated: November 7, 2026

Nexus-Backup is a personal, non-commercial backup project using rclone and Google Drive.

Google Drive access

The application uses Google OAuth authorization to upload, list, download and manage backup files in the owner's Google Drive account.

Data storage and security

Backup archives are encrypted locally before being uploaded to Google Drive using rclone crypt. OAuth credentials are stored on the owner's server.

Data sharing

Encrypted backup files are stored with Google Drive. Nexus-Backup does not sell user data or share it with advertisers.

Control and revocation

The owner controls the backup files and can revoke Google access through their Google Account security settings.
